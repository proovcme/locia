# Атлас — исходники публичного IFC viewer

[Открыть Атлас](https://locia.work/atlas/) · [Все инструменты](../../README.md)

TypeScript, Three.js, That Open Components и web-ifc. Загрузка IFC с компьютера, несколько моделей в сцене, дерево и свойства элементов, видимость, сечения и измерения. Файлы обрабатываются в браузере.

## Сборка и запуск

Нужны Node.js 22.12+ и npm. Из корня репозитория:

```sh
cd apps/atlas
npm ci
npm run build
npm run preview
```

Откройте `http://127.0.0.1:4173/atlas/`. Готовый сайт — `dist-public-atlas/`; разместите его на HTTP-сервере по пути `/atlas/`. Запуск через `file://` не поддерживается из-за WASM и workers.

Сборка загружает 23 открытые модели buildingSMART, сверяет размеры и SHA-256 по `public-models.lock.json` и очищает персональные метаданные авторов. Для первой сборки нужен интернет. Атрибуция включается в результат автоматически.

После изменения кода повторите `npm run build` и обновите страницу preview.

## Происхождение и границы

Код публичной версии из исходной ревизии `6095d7009138d13666f99c106d9acdbdb4f5d07f`, указанной в [манифесте](../../manifest/public-release.json). Повторная сборка побайтово совпадает с `public/atlas/`. Конфигурация сборки задаёт `VITE_PUBLIC_ATLAS=1`. Приложение работает на статическом HTTP-сервере и использует каталог открытых моделей buildingSMART.

`public/atlas/` в корне репозитория содержит прежнюю готовую сборку для Docker Compose. `npm run build` проверяет и собирает исходники отдельно и не заменяет развёрнутый сайт автоматически.
