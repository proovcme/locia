# PDF-редактор проектной документации

Web-адаптация приложения из [`proovcme/pir_utilitys#2`](https://github.com/proovcme/pir_utilitys/pull/2), закреплённая на commit `9470cce726a2cdbcad1be3efaec12e16c94bff37`.

Frontend сохраняет рабочие сценарии исходного Tauri-приложения, а локальные системные диалоги и Python-sidecar заменены на браузерную загрузку и изолированный HTTP API. Переданные документы обрабатываются во временном каталоге контейнера и удаляются после ответа.

Ограничения публичного контура: до 20 файлов, 24 МБ суммарно, 160 страниц на PDF и 50 секунд на одну операцию. PDF с паролем не принимаются.
