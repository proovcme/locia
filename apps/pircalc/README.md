# Калькулятор — исходники публичной веб-версии

[Открыть калькулятор](https://locia.work/pircalc/) · [Все инструменты](../../README.md)

React, TypeScript и ExcelJS. Расчёт по нормативным данным ФГИС ЦС, формы 2П, 3П и 4П, расшифровка расчёта и выгрузка XLSX. Данные пользователя сохраняются в браузере.

## Сборка и запуск

Нужны Node.js 22.12+ и npm. Из корня репозитория:

```sh
cd apps/pircalc
npm ci
npm run build
npm run preview
```

Откройте `http://127.0.0.1:4173/pircalc/`. Готовый сайт — `dist-public/`; разместите его на HTTP-сервере по пути `/pircalc/`. Для разработки: `npm run dev`, затем `/pircalc/public-pir.html`.

Публичный вход — `src/public-main.tsx`. В `src/domain/` находятся формулы и правила, в `src/services/` — экспорт Excel, в `src/data/` — зафиксированный нормативный снимок. Сборка проверяет отсутствие внутренних модулей и обращений к ERP.

## Происхождение и данные

Это публичная веб-ветка калькулятора из ревизии `0ad2b19`, указанной в [манифесте](../../manifest/public-release.json). Повторная сборка побайтово совпадает с `public/pircalc/`. Исходный настольный проект развивается в [proovcme/pir_utilitys](https://github.com/proovcme/pir_utilitys). Здесь опубликовано дерево зависимостей публичного входа; настольная оболочка и директорский портфель в него не входят.

Нормативный снимок относится к августу 2026 года; выбранный исходный период индексов — II квартал 2026 года. Данные не обновляются автоматически. Перед рабочим расчётом проверьте применимость нормативов и актуальность индексов по ссылкам на ФГИС ЦС в интерфейсе.

`public/pircalc/` в корне репозитория содержит готовую сборку для Docker Compose. `npm run build` собирает исходники отдельно и не заменяет развёрнутый сайт автоматически.
