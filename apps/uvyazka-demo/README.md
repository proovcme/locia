# Увязка: публичное 3D-демо

[Открыть](https://locia.work/uvyazka/) · [Исходники Увязки](https://github.com/proovcme/uvyazka)

Статическая сборка вьювера Увязки с расчётным ядром IFCCS 0.5.
22 синтетических элемента АР и ОВ, 143 работы, два варианта ресурсов,
журнал, Гант, сцены, разрез и анимация площадки. Демо воспроизводит готовый
расчёт. Пользовательские файлы, API Увязки и генерация моделью не подключены.

Код вьювера и генератор данных поддерживаются в отдельном репозитории,
второй копии исходников здесь нет. Сборка из корня checkout Увязки:

```sh
uv sync --extra all --extra authoring
cd web && npm ci && cd ..
uv run python tools/build_demo_site.py
```

Для развёртывания используйте только `.uvyazka-build/public-site/uvyazka/`.
[Подробности и ограничения](https://github.com/proovcme/uvyazka/blob/main/docs/PUBLIC_DEMO.md).
Витрина `site/index.html` ссылается на `/uvyazka/` и GitHub Увязки.
Статическая страница размещается отдельно от PHP-приложения Locia;
основной compose этой поставки её автоматически не собирает и не разворачивает.
