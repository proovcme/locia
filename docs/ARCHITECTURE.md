# Архитектура публичного контура

```text
Browser
  │
  ▼
Caddy :8080
  ├── /                 static showcase
  ├── /lemma/*          reverse proxy → PHP demo :8080
  ├── /atlas/*          static WebGL/IFC application
  └── /pircalc/*        static estimate calculator
```

## Лемма

PHP-приложение работает только в demo mode. SQLite создаётся из схемы на старте, затем наполняется синтетическими ролями, проектами и задачами. Сессии и база находятся в отдельном volume; перезапуск пересобирает базу.

## Атлас

Статическая Vite-сборка использует Three.js, That Open Components и web-ifc. Каталог содержит 23 модели buildingSMART. Модели скачаны из закреплённого commit, проверены по SHA-256 и очищены от полей персон и авторов.

## Калькулятор

Статическая браузерная сборка содержит только публичные формы расчёта. Расчёты выполняются на стороне клиента; серверное хранилище не используется.

## Сеть

Наружу опубликован только Caddy. Контейнер Леммы доступен во внутренней compose-сети. Служебных update, notify и Revit endpoints в этом проекте нет.
