# Public boundary

Этот репозиторий отделён от production по данным, конфигурации и назначению.

В него входят:

- синтетический demo seed Леммы;
- браузерные публичные сборки Атласа и калькулятора;
- открытые IFC buildingSMART;
- локальный Docker Compose для демонстрации.

В него не входят:

- production базы и резервные копии;
- реальные сотрудники, контакты, проекты, вложения и модели;
- ключи, токены, пароли, SMTP-настройки и сертификаты;
- `/locia-update`, `/locia-notify` и production Revit API;
- операторские скрипты и конфигурация рабочих серверов.

Публичность репозитория не означает публичность какого-либо другого контура Locia.
