# Граница публичного репозитория

Этот репозиторий отделён от production Locia по данным, конфигурации и инфраструктуре.

В репозиторий входят исходники self-host приложения, миграции MariaDB, синтетический demo seed, публичные сборки Атласа и Калькулятора, web-исходники PDF-редактора и открытые IFC buildingSMART.

В репозиторий не входят production-базы и backups, реальные сотрудники и проекты, клиентские модели, ключи, токены, SMTP-настройки, сертификаты, конфигурация рабочих серверов, `/locia-update/`, `/locia-notify/` и production Revit API.

Рабочие данные self-host установки создаются владельцем на его сервере и сохраняются только в его Docker volumes. Файл `.env.work` и каталог `backups/` исключены из Git и Docker build context.

Публичность этого репозитория не означает публичность какого-либо другого контура Locia.

PDF-редактор принимает документы только для выполнения выбранной операции. Файлы находятся во временном каталоге изолированного контейнера, не попадают в volumes, журналы или резервные копии и удаляются после формирования ответа.
